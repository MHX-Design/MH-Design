Black Moss Shell

Black Moss Shell is a personal game UI/UX and motion design project. It is a third-person tactical stealth concept set in a decaying, post-industrial world where nature has reclaimed much of humanity's technology. The project focuses on designing the pre-game customisation menus for characters, weapons, and equipment, combining UI/UX, motion, interaction, and visual design.

The interface reflects the game's tone through minimal, intuitive UX, with motion, sound, and visual design working together to enhance immersion with clear, tactical decision-making before gameplay begins.

Role: UI/UX - Motion Design - Visual Design - Interaction Design

Tools used: Figma, After Effects, Photoshop, Illustrator, AI-Assisted Tools*
*character, weapon, equipment, audio, and supporting copy assets

User Flow & System Overview

Feature-heavy game interfaces can create cognitive overload and reduce usability. The aim of Black Moss Shell was to keep navigation focused and readable, allowing players to make fast tactical decisions without unnecessary complexity.

The menu flow was designed around a simple hierarchy, moving players from the main menu into customisation screens with minimal steps and clear navigation states.

A modular stat system spans characters, weapons, and equipment, introducing variables such as damage, noise, range, reload time, weight, and tactical modifiers that influence playstyle and strategy.

Interface Design

I used sketches and low fidelity wireframes to explore layout, hierarchy, and navigation before developing the final interface screens. A consistent grid system helped maintain clarity across character, weapon, and equipment menus.

The art direction focused on visuals inspired by nature's takeover, futuristic interfaces, and atmospheric stealth games.

Motion & Interaction

Storyboard sketches were used to plan transitions and interface behaviour before animating. Motion focused on layered UI movement, sequential loading, and responsive state changes designed to guide navigation and reinforce player interaction during customisation.

Audio was later added to enhance feedback, atmosphere, and overall immersion throughout the interface experience.
